# Catalog provenance

The original six curated records are supplemented by 60 real Open Library work records retrieved on 2026-10-31 through six small batched Search API requests. Title, primary author, work identifier, first-publication year and cover identifier come from Open Library. Category assignments were reviewed for this library. Each record retains an Open Library source link.

Descriptions for imported books are bibliographic notes, not publisher summaries. Copy counts and dates added are BookNook demo inventory, not statements about Open Library lending availability. Published covers are served by the Open Library Covers API. No covers were generated or redesigned.

The checked-in snapshot keeps browsing independent of an upstream metadata API. The backend seed contains the same catalog; it inserts missing records without replacing existing copies or user changes. Preview and MongoDB IDs differ deliberately; live IDs are generated by MongoDB.

Source documentation: https://openlibrary.org/developers/api and https://openlibrary.org/dev/docs/api/covers
